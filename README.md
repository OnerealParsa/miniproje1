# Mini Project 1 — Student Records (C++)

A university assignment in C++: a single-file console program that manages student records stored in a linked list, with duplicate student-ID detection on insertion.

## Features

- Add a student record (name, student ID, units, GPA, security code)
- Rejects duplicate student IDs
- Linked-list based storage

## Build & Run

```bash
g++ -std=c++17 -O2 -o students miniproje1.cpp
./students
```

## Concepts Demonstrated

Manual linked-list implementation, duplicate detection, record management.
